## 1. What it is

- An open-world sailing, cartography and island-crawl RPG in the browser. You sail a streamed procedural sea and chart it through fog of war. Ashore you clear island crawls with combat, loot, biomes and caves. You also fish and whale, trade in ports and towns, walk your own deck with a crew, play through a guided story (INTROSTORY), and hear music from the game's own engine (THE BARD).
- There is no build step: plain HTML, CSS and JS served as-is. The game is `boats/index.html` (~3.3 MB: markup, CSS and 21 inline script parts) plus 33 classic `<script src>` files in `boats/js/` that share one global scope (§4). The other files are `boats/sfx/` (CC0 samples and `manifest.json`) and this guide.
- The owner is not a programmer and judges by playing. Report in plain language: what changed, what to play, and what you're unsure of.

## 8. Known traps (each has broken the game, or can in a split build)

1. **Duplicate top-level names.** Two `let hull` declarations once froze the game; the real one is at 14110. Across classic script files, a duplicate `let`/`const` kills the whole later file. Lint check 3 catches it.
2. **Comment-swallowed code.** An unclosed `/*` or a stray `//` can silently disable real code. Lint check 4 catches it. The mid-line block comments at 9534 and 9691 (live code before and after them) and at 9922 and 9923 (code before them; the latter also ends with a `//` comment) are deliberate and must stay closed.
3. **Emoji vs `\uXXXX` text.** Literal escape *text* sits on 4198-4205, 18705, 19714, 19789-20015 (mixed with real emoji) and proving_dev.js:41. Deliberate JS escapes sit at hud_kit.js:269 and 13975 (`\uFE0F`) and at 21215 and 21273 (`\u0001`/`\u0002`). Everything else is real UTF-8. A search for one form misses the other. Copy bytes exactly; never re-encode or normalise line endings.
   - **git writes CRLF here.** `core.autocrlf=true` is set in the system gitconfig and the repo has no `.gitattributes`, so a plain `git checkout`, `restore`, `stash`, `switch`, `worktree add`, `merge`, `pull`, `cherry-pick` or `reset --hard` can write a boats file with CRLF (always pass `-c core.autocrlf=false`); the lint's SCRIPTS check goes RED and split_move.ts refuses it. Undo a boats file with `git -c core.autocrlf=false checkout -- boats/<path>`.
4. **Load-time order.** Keep the 406 load-time statements in their relative order (the approved `{ move }`s of P2-P4 aside). Function declarations hoist only within their own script. Nine "hoisting pairs" call a function declared below them, so never put a file boundary between: 1927/1928, sea_lands.js:70/71, 6160/6162, 9043/9085-9218, 10660/10662-10664, deck_art.js:367/385, 19210/19453, 20220/20223, style_pass.js:39/40.
   - **The one accepted conditional need (lead decision D2):** 1431 `resize();` reaches `townPixFor` (towns.js:64) and `islZoomApply` (1434) only when `townPixOn`/`islPixOn` is set, and both are false at load. `lint_allow.json` holds `{ "stmt": "resize();", "name": "townPixFor", … }`, used since `crawl2.js` put a file boundary between them; `islZoomApply` needs no entry (same part). The lint ends `LINT GREEN (1 warning check)`; that WARN (handlers that can run between files, trap 10) is expected and cannot be cleared.
